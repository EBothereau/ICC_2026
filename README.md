# Code for "Lightweight Preprocessing and Feature Extraction for LoRa RF Fingerprint Identification"
Code associated with:
E. Bothereau et al., "Lightweight Preprocessing and Feature Extraction for LoRa RF Fingerprint Identification," IEEE International Conference on Communications (ICC), Glasgow, United Kingdom, 2026, pp. 1-6, doi: 10.1109/ICC59461.2026.11587750. 


This code is the basis used for the generation of the presented results. 



selected_indexes.bin and lda_proj.bin respectively presents the I index list and the M projection matrix.
